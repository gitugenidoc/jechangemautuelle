# 🎯 Prompt de Génération - Landing Page Jobs

## Prompt Complet à Utiliser

```
Tu es un expert en développement web frontend. Crée une landing page jobs PARFAITE pour "Je Change Ma Mutuelle" avec:

**DESIGN & STYLE:**
- Design moderne, unique, premium (pas d'IA générique)
- Meilleur que le site jechangemamutuelle.online
- Couleurs: vert primaire (#00a86b) + orange accent (#ff6b35)
- Animations fluides, dégradés, blobs animés
- Responsive mobile-first
- TailwindCSS-like (pas de framework externe)
- Pas de dépendances externes

**SECTIONS:**
1. Navigation sticky avec logo JCM
2. Hero section avec titre impactant + badges + CTA
3. Pourquoi nous rejoindre (6 cards avec icons emoji)
4. Formulaire de candidature complet
5. Footer avec contacts

**FORMULAIRE:**
- Champs: Prénom, Nom, Téléphone, Email, Ville, Années d'Expérience, Présentation, CV
- Design moderne avec labels clairs
- Validation HTML5
- Upload CV avec drag & drop
- Checkbox conditions
- Intégration Formspree.io (action="https://formspree.io/f/xyzgwopq")
- Bouton submit élégant

**FICHIERS A CRÉER:**
1. index.html - Structure complète
2. styles.css - Tous les styles (pas de CSS externe)
3. script.js - Animations, interactions, validation
4. README.md - Guide installation + déploiement

**INTERACTIVITÉ:**
- Animations au scroll
- Smooth scroll sur les ancres
- File upload avec drag & drop
- Navigation highlight au scroll
- Formatage automatique téléphone
- Feedback utilisateur fluide

**DÉPLOIEMENT:**
- Accessible sur: jechangemamutuelle.online/jobs
- Compatible avec Formspree.io
- Pas de serveur backend requis
- Statique HTML/CSS/JS pur

Génère le code complet, prêt à déployer.
```
